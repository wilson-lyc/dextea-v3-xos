# 对象存储中台 API 文档

本系统提供统一的文件上传接口。业务方无需关心底层对接的是哪家对象存储（MinIO、阿里云 OSS、腾讯云 COS 等），只需在调用时指定**存储源名称**即可。

## 目录

- [文件上传](./upload.md)
- [图库](./gallery.md)

## 通用约定

### Base URL

```
http://<服务地址>:8080/api/v1
```

### 请求

- 除上传接口为 `multipart/form-data` 外，其余接口均为 `application/json`（如有）。
- 每个响应都会携带 `X-Request-ID` 响应头，排查问题时请提供该 ID。

### 响应

统一响应结构如下，`code` 为 0 表示成功，非 0 为业务错误码（与 HTTP 状态码解耦）：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

常见业务错误码：

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40400 | 资源不存在（如存储源、图库记录） |
| 50000 | 服务端内部错误 |

HTTP 状态码遵循标准语义：200 成功、400 参数错误、404 资源不存在、500 服务端错误。
